# 06 — Post-MD analysis outputs

This directory is reserved for harmonized per-system outputs from post-production MD analysis of the 15-enzyme DMCS panel.

## Scope

The collection covers four analysis categories:

- `RMSD/` — structural deviation time series
- `Rg/` — radius-of-gyration time series
- `SASA/` — solvent-accessible surface area time series
- `Hydrogen_Bonds/` — hydrogen-bond count/occupancy time series

Only actual result outputs from the 15 explicitly defined DMCS source directories are in scope. RMSF is maintained separately in the DMCS analysis data. MMPBSA/MMGBSA summary files are not SASA outputs and must not be included in this collection.

## Required data organization

Each system is stored under its original source-directory name, with results grouped by category and original relative subfolder. Original `.dat` files must be retained byte-for-byte. A matching `.csv` export is supplied only when the DAT contains a parseable numeric table. CSV conversion is a format transformation and must not recalculate or alter the underlying values.

## Provenance and QC files

The completed collection must include:

- `POST_MD_DAT_MANIFEST.csv` — enzyme, source directory and relative path, category, copied path, file size, SHA256, CSV path and conversion status.
- `POST_MD_SYSTEM_INVENTORY.csv` — per-enzyme counts by category.
- `README.md` — data scope, collection notes and interpretation.
- A QC report recording source/copy checksum validation and any exclusions.

## Collection audit status

A first-pass collection found 690 DAT files across all 15 systems. All 690 copies were verified against their source files by SHA256, with no missing files, checksum mismatches, duplicate-content groups or irregular numeric rows. However, filename/content classification incorrectly assigned 45 `FINAL_RESULTS_*_MMPBSA.dat` energy-summary reports to SASA. Those reports are not SASA time series and the first-pass collection is therefore not suitable for publication.

A corrected collector explicitly excludes MMPBSA/MMGBSA reports. Based on the first-pass audit, the expected post-correction inventory is 645 DAT files: 165 RMSD, 150 Rg, 150 SASA and 180 hydrogen-bond files. The expected 585 numeric CSV conversions exclude 60 non-tabular hydrogen-bond average reports, which remain preserved as original DAT files. These are expectations only; the final manifest and inventory generated by the corrected run are authoritative.

**Current status: corrected collection and final verification pending. Do not cite this folder as a deposited completed dataset until the corrected output files and QC report are present.**

## Interpretation cautions

Before quantitative cross-system comparison, confirm consistent atom masks, reference structures, surface definitions, donor/acceptor selections, hydrogen-bond geometric cutoffs, trajectory sampling intervals and equilibration windows. A file count alone does not establish methodological comparability.
