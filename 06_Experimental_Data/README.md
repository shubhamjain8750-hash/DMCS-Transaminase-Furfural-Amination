
# 06 - Experimental Data

## Overview

This directory contains the experimental data supporting the recombinant expression, purification and biocatalytic evaluation of ATA117-Rd11 for the amination of biomass-derived furfural.

## Experimental Studies

### 1. Recombinant Expression and Purification
- Recombinant ATA117-Rd11 expression data.
- Protein purification records.
- SDS-PAGE supporting data.

### 2. Furfural Amination
- Reaction conditions.
- Furfural conversion data.
- Furfurylamine product formation.
- HPLC analytical data.

### 3. Reaction Optimization
- Reaction time optimization.
- pH optimization.
- PLP concentration optimization.
- Enzyme loading optimization.

### 4. Preparative-Scale Evaluation
- Gram-scale reaction conditions.
- Furfural conversion.
- Product yield and associated analytical data.

## Data Formats

Experimental source data will be provided in machine-readable CSV format, with relevant chromatograms and supporting analytical files where available.

## Reproducibility

The datasets are intended to support independent evaluation of the experimental findings reported in the manuscript.
