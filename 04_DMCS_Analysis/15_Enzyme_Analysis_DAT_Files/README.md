# 15-enzyme analysis DAT outputs

This directory contains all `.dat` files collected from each of the 15 selected enzyme analysis folders. Each enzyme has its own source-named subfolder. Original filenames and file contents are preserved.

The manifest records file size, SHA256 and a broad data category. File types include distance series, protein/complex/ligand RMSF outputs, clustering summaries and assignments, and MM/GBSA results when present. The `.dat` files are analysis outputs; matching CPPTRAJ/MMPBSA input definitions are documented in the DMCS methods documentation and the system input archive.
