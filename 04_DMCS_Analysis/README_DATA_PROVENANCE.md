# Data provenance and file definitions

- `DMCS_15_SYSTEM_RAW_DESCRIPTORS.csv`: source-file means and frame counts, dominant cluster statistics, signed GB/PB energies, protein residue counts and pocket summaries.
- `DMCS_ACTIVE_SITE_RESIDUES.csv`: per-residue membership in the canonical 5.0 Å pocket, residue name, minimum distance to UNP/UNL/UNI, nearest ligand/cofactor and Cα RMSF.
- `DMCS_RMSF_CUTOFF_SENSITIVITY.csv`: pocket mean, normalized component scores, composite score and rank at each pocket boundary.
- `DMCS_RESULTS.csv`: raw descriptor matrix supplied to S2.
- `DMCS_STANDARDIZED.csv`: normalized components and composite DMCS.
- `DMCS_Final_Ranking.csv`: sorted ranking.

The common RMSF source is `rmsf_protein_calpha.dat`, generated by system-specific `cpptraj.in` after protein-backbone RMS fitting. The structure-derived pocket definition and averaging equation are specified in `DMCS_RMSF_METHOD.md`.
