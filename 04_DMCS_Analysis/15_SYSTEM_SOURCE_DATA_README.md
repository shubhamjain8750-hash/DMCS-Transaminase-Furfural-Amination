# Additional 15-system source-data packages

Two source-data collections are organized under these folders:

- `04_DMCS_Analysis/15_Enzyme_Analysis_DAT_Files/` — original per-enzyme `.dat` analysis outputs and `DAT_FILE_MANIFEST.csv`.
- `03_MD_Inputs/15_Enzyme_MD_Complex_Structures/` — prepared protein–PLP–furfural–isopropylamine complex PDBs and stage-2 equilibration snapshots, with `PDB_STRUCTURE_MANIFEST.csv`.

Each folder contains one subfolder per enzyme. The file manifests provide SHA256 checksums for source-integrity verification.
