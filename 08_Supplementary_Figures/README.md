
# 08 - Supplementary Figures and Source Data

## Overview

This directory contains supplementary figures and associated source data supporting the computational and experimental findings reported in the manuscript.

## Supplementary Figures

The following supplementary materials are intended to be included:

- Figure S1: Supplementary computational analysis.
- Figure S2: Supplementary molecular dynamics analysis.
- Figure S3: Additional structural and computational analysis.
- Figure S4: Supplementary experimental HPLC analysis.

## Source Data

Where available, machine-readable source datasets associated with the supplementary figures will be provided in CSV or other appropriate formats.

## File Formats

- PDF: Supplementary figures.
- PNG/TIFF: High-resolution figure images, where appropriate.
- CSV: Underlying numerical source data.

## Reproducibility

The supplementary materials provide additional information supporting the computational methodology, enzyme evaluation and experimental findings described in the manuscript.
