
# 05 - Processed Computational Data

## Overview

This directory contains machine-readable datasets and processed computational results generated during the screening, evaluation and prioritization of PLP-dependent transaminases using the DMCS framework.

## Dataset Categories

### Initial Enzyme Screening
- Docking results for the 22 initially screened enzymes.

### Homolog Evaluation
- Sequence similarity and docking results for the selected homologous transaminases.
- Comparative DMCS evaluation data.

### Benchmark Enzyme Evaluation
- Computational results for AB-R-ATA and CV-TAm.

### Catalytic-Site Variant Evaluation
- Docking and DMCS results for Lys188 substitution variants.

### DMCS Descriptor Results
- Raw descriptor values.
- Normalized descriptor values.
- Individual descriptor scores.
- Composite DMCS scores and enzyme rankings.

## Data Formats

Datasets will be provided in machine-readable CSV format.

## Reproducibility

These datasets are intended to support independent inspection and reproduction of the computational results and comparative analyses reported in the manuscript.
