
# 07 - Computational Environment and Software

## Overview

This directory documents the computational software, libraries, dependencies and execution environments used in the DMCS study.

## Computational Software

The study involves the following computational tools:

- AMBER24: Molecular dynamics simulations.
- CPPTRAJ: Molecular dynamics trajectory analysis.
- AutoDock Vina: Molecular docking.
- Python: Data processing and DMCS calculations.
- PyMOL: Molecular structure visualization.

## Software Versions

Exact software versions, build information and relevant configuration details will be documented in software_versions.txt.

## Python Dependencies

Python dependencies required for the DMCS analysis will be provided in requirements.txt or environment.yml.

## Reproducibility

The environment documentation is intended to help researchers configure the computational environment required to execute the supplied analysis scripts.
